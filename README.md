## 🚀 Getting Started

### 1. Install Python

Download Python from the official website:

https://www.python.org/downloads/

### 2. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/python-from-basics-to-advanced.git
```

### 3. Navigate to the Repository

```bash
cd python-from-basics-to-advanced
```

### 4. Run a Python File

```bash
python3 filename.py
```

### 5. Work with Jupyter Notebook

```bash
pip install notebook
jupyter notebook
```
